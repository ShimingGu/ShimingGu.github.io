# 首页 3D 宇宙网设计简报

## 概念
让访客感觉正在观察一小片有真实纵深、仍在缓慢生长的宇宙网，而不是一张平面连线图。

## 需求清单
- 替换首页右侧现有 2D Canvas 宇宙网，不改其他页面结构。
- 保留白底、黑灰节点、细纤维和克制动态。
- 默认缓慢自转；指针拖拽可旋转；拖动有阻尼。
- 尊重 `prefers-reduced-motion`，页面隐藏或组件离屏时暂停自动渲染。
- 桌面约 320 × 320 CSS px；移动端沿用现有隐藏策略。
- WebGL 不可用时保留静态 SVG 图形。
- 构建通过，并在浏览器检查画面、拖拽、控制台和资源释放。

## 现有视觉特征 → 实现方式
| 现有特征 | 三维实现 |
| --- | --- |
| 黑灰小节点 | 低饱和球形节点，中心节点略大 |
| 细而弯曲的连接 | 二次贝塞尔纤维采样后合并绘制 |
| 少量移动脉冲 | 少量小球沿三维纤维运动 |
| 大留白 | 透明背景，不添加地面、边框或面板 |
| 轻量装饰 | 实例化节点、合并线段、限制像素比 |

## 尺度与构图
- 使用抽象场景单位；网络主体半径约 2.1。
- 5 个星系团中心，团内 7–10 个节点，并添加跨团纤维与少量孤立点。
- 透视相机 FOV 38°，位于 z = 7.2；完整旋转时不裁切主体。
- 初始倾角约 x = -0.18、y = 0.55，让纵深在第一帧可见。
- 使用固定随机种子，保证每次加载构图一致。

## 色彩与材质
- 节点：`#1d1d1f`，粗糙度 0.48，金属度 0.05。
- 纤维：`#1d1d1f`，透明度约 0.18，不写深度。
- 脉冲：`#1d1d1f`，透明度约 0.65。
- 节点光晕：程序化径向灰度纹理，透明度不超过 0.14。
- 背景：完全透明，沿用页面现有色彩晕染。

## 光线
- 环境光提供基础可读性；单个方向光形成轻微的球面明暗。
- 不启用阴影、后处理或 bloom，避免小尺寸画面变脏。

## 检查视角
- 默认主视角：节点、团簇与长纤维完整可见。
- 拖拽后的侧向视角：主体仍在画布内，深度关系清楚。
- 减少动态效果：无自动旋转和脉冲移动，仍可手动旋转。
- 窄屏：组件按现有规则隐藏，不影响正文。

## 交互
- 按下并拖动：旋转网络；释放后带少量惯性。
- 停止交互后恢复极慢自转；减少动态效果时不自转。
- 不添加缩放、点击菜单、HUD 或额外说明文字。

## 可调整项
- 本组件属于现有网站装饰，不建立独立编辑器项目。
- 密度、速度、颜色、倾角和相机参数集中在组件代码中维护。

## 性能预算
- 节点使用 InstancedMesh；所有纤维合并为一个线段几何体。
- 节点与脉冲各一次主要绘制，纤维一次，光晕一次。
- 球体采用低细分；像素比最高 2；离屏和后台暂停。
- 不下载纹理、模型或环境资源。

## 技术路线
- 所有节点、纤维、光晕、运动和交互均由 Three.js 程序化生成。
- 无需 Blender：没有复杂曲面、有机角色或需要 UV 烘焙的静态资产。
- 无外部素材或许可证依赖。
